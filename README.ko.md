# munroni-mode

[English](README.md)

[Claude Code](https://claude.com/claude-code)용 작업 방식 스킬입니다. 켜 두면 Claude가 첫 줄에 답부터 쓰고, 맡은 일은 중간에 묻지 않고 끝내고, 되돌리기 어려운 일만 먼저 묻고, 자기 결과를 스스로 검사하고, 화면과 글을 담백하게 만듭니다.

## 켜기 전과 켠 뒤

**끝난 일 보고**

> **켜기 전:** 버튼 색을 바꿨습니다. hover 색도 바꿀까요? 원하시면 테스트도 돌려 보겠습니다.
>
> **켠 뒤:** 끝났습니다. 같은 버튼이 3곳에 있어서 3곳 다 바꿨습니다. 타입 검사와 린트를 통과했습니다. 브라우저에서 /settings 의 저장 버튼을 보시면 됩니다. 커밋은 안 했습니다.

**갈림길**

> **켜기 전:** 저장 방법이 두 가지입니다. 새 칸을 추가할까요, JSON 칸에 넣을까요?
>
> **켠 뒤:** 새 칸을 추가하고(마이그레이션 V12, 다시 돌려도 안전) 화면까지 끝냈습니다. JSON 칸으로도 됩니다. 나중에 바꾸려면 마이그레이션 하나면 됩니다.

**막연한 불만: "이 화면 비어 보여"**

> **켜기 전:** 네! 큰 배너, 기능 카드, 그라데이션 배경을 넣어 화면을 새로 꾸몄습니다.
>
> **켠 뒤:** 비슷한 실제 서비스를 찾아 방향이 다른 시안 3개를 한 파일로 만들어 브라우저에 열어 두었습니다. B안을 추천합니다. 코드는 아직 건드리지 않았습니다.

## 맞는 사람

- 일을 맡기면 끝내고 검사까지 마친 결과를 받고 싶고, 커밋, 푸시, 배포, 삭제, 바깥으로 나가는 메일만 확인하고 싶은 사람에게 맞습니다.
- 단계마다 승인하고 넘어가고 싶은 사람에게는 맞지 않습니다.

## 담긴 규칙

| 칸 | 핵심 규칙 |
|---|---|
| 답변 | 첫 줄에 답부터, 쉬운 말로. 정할 일은 추천 하나를 붙인 번호 선택지로 묻습니다. |
| 자율성 | 중간 질문 없이 끝까지. 되돌리기 어려운 일만 먼저 묻고, 시킨 것만 합니다. |
| 위임 | 큰 일은 하위 에이전트를 병렬로 돌립니다. 같은 저장소에 다른 세션이 있다고 보고 남의 변경은 되돌리지 않습니다. |
| 검증 | 테스트, 타입 검사, 린트. 만든 것은 직접 열어 주고, 결과를 지어내지 않습니다. |
| 진행 방식 | 구체적인 지적은 그것만 고칩니다. 막연한 불만에는 시안 3안부터 냅니다. 같은 패턴은 앱 전체에서 같이 고칩니다. |
| 코드 | 반복되는 UI는 공용 부품 하나로. 사용자가 고친 파일은 통째로 다시 만들지 않습니다. 시험과 예시에는 가짜 값만 씁니다. |
| 메모 | 정한 것과 남은 일을 적어 다음 세션이 이어받게 합니다. |

필요할 때만 읽는 참고 파일이 두 개 있습니다.

- `references/ui-defaults.md`: 화면을 만들기 전에 읽습니다. 장식 금지, 표 정렬, 빨강의 뜻, 창 규칙, 입력 편의, 폰 배치
- `references/writing.md`: 글을 쓰기 전에 읽습니다. AI 말투 금지, 바깥 독자를 위한 쉬운 말, 한 장 요약, 다른 세션에 넘기는 프롬프트 틀

## 판

| 스킬 | 규칙 언어 |
|---|---|
| `munroni-mode` | 영어(기본) |
| `munroni-mode-ko` | 한국어 |

두 판의 규칙은 같습니다. 어느 판을 써도 답은 사용자가 쓰는 언어로 합니다.

## 설치

플러그인으로 설치:

```
/plugin marketplace add ruddbs273-hue/munroni-mode
/plugin install munroni@munroni
```

설치한 뒤 `/munroni:munroni-mode-ko`(영어판은 `/munroni:munroni-mode`)를 칩니다.

복사해서 설치할 수도 있습니다. `skills/munroni-mode-ko`(또는 `skills/munroni-mode`) 폴더를 `~/.claude/skills/` 아래에 넣고 `/munroni-mode-ko`를 칩니다.

## 참고

- 명령을 쳐야만 켜집니다(`disable-model-invocation: true`). Claude가 알아서 불러오지 않습니다.
- 한 사람의 취향입니다. 포크해서 규칙을 고치고 이름을 바꿔 자기 것으로 쓰면 됩니다.
